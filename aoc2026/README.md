# Advent of Code 2026

Let's celebrate the holiday!

## Solve a problem

`npm run aoc2026 -- solve --day 1 --part 1 --inputFilePath path/to/input.txt`

## Run some tests

`npm run test`

`npm run test -- src/path/to/target/folderOrFile`

`npm test -- src/path/to/target/file -t "test matcher phrase"`

## Format, check, etc.

`npm run format`

`npm run lint`

`npm run check`

## Generate solution skeletons

`npm run aoc2026 -- generate --targetDir /path/to/aoc2026/src`

Warning: This is not very specific, it just blows away everything in that directory:

`npm run aoc2026 -- generate --clean --targetDir /path/to/aoc2026/src`
